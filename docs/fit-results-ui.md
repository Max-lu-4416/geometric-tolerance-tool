# 配合结果区精修

日期：2026-11-09；本地 v1.3.2 预览。

产品：供机械设计人员选公差带、核对孔轴配合。
性格：克制、精确、耐看。
视觉环境：工程图纸、量检具；沿用石墨灰、工程蓝和等宽数值。
重点：先读配合性质与间隙/过盈数量，再核对孔轴数据与真实比例图。
识别：孔蓝、轴橙与公差带图一致，比较数据保持对照表结构。

原区域的问题：配合范围与辅助文字字号接近；偏差、宽度和尺寸混排，单位重复；孔轴标识与图解脱节；六个复制按钮优先级接近。沿用现有品牌与页面结构，只精修结果区域。

- 间距：两类配合页的结果区域由 244 调整至 276，矩阵行由 40 调整至 36；矩阵内容及选择规则保持，六页无页面滚动条。
- 颜色：孔轴行以不同颜色标识，数字保持中性色，范围为工程蓝；深色标签满足对比度要求，图解白底保留。
- 图标：不添加装饰图标、图片或动画。
- 文案：性质、最小/最大间隙和过盈分别标注；过渡配合不把负差值混写为间隙范围。重复尺寸段合并显示。
- 字体：范围 24、表内数值 15、分组说明 12；单元格数值完整显示，过长时等比例缩放并提供完整提示。
- 布局：保留孔轴对照表，分组表头为偏差 / mm、公差 / μm、极限尺寸 / mm；数字右对齐。
- 细节：增加组间分隔和列间距；复制尺寸标注、完整结果放前面，四项偏差复制保持一键可用。
- 图解：沿用真实比例及零线，不改变计算规则。
- 动效：不增加循环动画或额外步骤。

88 组复制文本继续与 v1.3 原样本逐字比较，数据、接口和设置格式保持兼容。没有实施此前尚未确定的尺寸范围限制。本次为独立本地预览，已公开的 v1.3.1 保留。
