# 形位查询栏与顶部导航精修

日期：2026-11-09；本地 v1.3.5。

产品：为机械设计人员选公差、查值和复制标注数值。
性格：克制、精确、紧凑。
视觉环境：工程图纸与量检具，沿用石墨灰、工程蓝和等宽数字。
重点：选中的等级与可复制的公差值。
统一细节：细蓝选中线、等宽数值、明确的功能分组。

## 审阅发现

- 数字等级与 H/K/L 混排，选择类别不够明确。
- 主参数标签、范围、说明与结果元信息层级接近。
- 完整结果按钮被空白推到栏底，与数值分离。
- 六项导航等宽分散，关联页面缺少分组。

## 精修处理

1. 间距：按 4px 节奏重排等级、参数与结果，复制操作紧随结果；六页导航收紧并按功能分组。
2. 颜色：沿用工程蓝、石墨灰；当前页使用小面积浅底和短蓝线，非当前项次级文字。
3. 图标：保留既有专业符号，不新增装饰图标。
4. 文案：标注公差与未注公差分别标识，参数单位放入输入框右侧；合并类型、等级和命中区间，保留完整规则与错误原因。
5. 字体：数字等级与查询值使用 Consolas；保持微软雅黑与既有字级。0 级禁用仍清晰可辨。
6. 布局：保留三栏与六个页面顺序，mm/μm 结果同行、复制按钮靠近；设置位于导航右端。
7. 细节：明确选择、悬停、键盘焦点和输入焦点；点击数值、Enter/空格及完整结果复制行为保持。
8. 图解：沿用实际参数图例和公差带图，不添加装饰图片。
9. 动效：不新增循环动画或布局运动。

验证采用程序内 WPF 控件事件、断言与直接渲染，不使用 computer use、UI Automation、桌面输入或系统显示设置变更。预览审阅不超过三轮。

设计流程使用 [unslop](https://github.com/heydamir/unslop)，作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），CC BY 4.0；原有 NOTICE 和许可保留。
